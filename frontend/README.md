# Welcome to Geolore
It is an app that will enable one to connect with their culuture from wherever they are
Whether it is history, language, stories, beliefs system 
We have it !!!

Features:
* Language class - can be one on one or a group class
* History page
* Food page
* Fashion Page
* AI chatbot for any questions regarding your specificculture

Run this on the terminal to seed the .md files
`git
npx ts-node scripts/seedCultures.ts
`
